# HiClaw v1.0.9 → v1.1.0 Upgrade — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Project HoneyBadge from HiClaw v1.0.9 (all-in-one monolith) to v1.1.0 (split embedded-infra + lightweight manager), validate with V2.5 (per-workaround evidence + 90-min soak), delete v1.0.9 workarounds that v1.1.0 fixes, and migrate to K8s on ECS — delivered as two sequenced PRs.

**Architecture:** Two-PR sequence. PR-1 (this branch `ralph/1.1.0-upgrade`) splits the local docker-compose stack into `hiclaw-embedded` (Tuwunel + MinIO + Higress + Element bundled) and a lightweight `hiclaw-manager` (agent only); deletes the 6 known workarounds with per-workaround evidence; runs a 90-min local soak. PR-2 (fresh branch `ralph/1.1.0-upgrade-k8s` off merged master) ports the same split to `deploy/k8s/`.

**Tech Stack:** Docker Compose, Kubernetes (k3s on ECS), kustomize, HiClaw v1.1.0 images (`hiclaw-embedded`, `hiclaw-manager`, `hiclaw-worker`), bash init scripts, Python 3 (in-container json patches), pytest E2E.

**Spec:** `docs/superpowers/specs/2026-04-25-hiclaw-1.1.0-upgrade-design.md` — read first for full context (architecture, ECS budget, 6 workarounds table, V2.5 procedure, risks, rollback, deferred items).

**Branch / worktree:** `D:/dev/HoneyBadge/.claude/worktrees/1.1.0-upgrade` on branch `ralph/1.1.0-upgrade`.

### Task A3: Per-workaround failure evidence — folded into Phase C

**Status (decided 2026-04-25):** The original 6-cycle pre-capture loop is **dropped**. **Why the change:**
- Six pre-capture cycles on v1.0.9 = 6 × `--force-recreate hiclaw-manager` + warmup + ~7 min E2E ≈ 1.5–2 h, with no signal that we don't already get from Phase C.

Mitigation: Phase C's git history (the immediately preceding green commit on v1.1.0) **is** the A/B baseline — `git stash` + `docker compose up -d --force-recreate` reverts cheaply.
