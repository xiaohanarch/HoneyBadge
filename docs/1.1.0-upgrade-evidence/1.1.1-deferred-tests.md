## Skip Strategy

Two skip styles in use:

1. **Per-test decorator** — when only a subset of a file fails (preserves regression
   value of the passing tests in the same file).

   ```python
   @pytest.mark.skip(
       reason="Deferred to 1.1.1 — Category X (...). "
       "See docs/1.1.0-upgrade-evidence/1.1.1-deferred-tests.md"
   )
   def test_tcXXX_...(...):
   ```

2. **Module-level `pytestmark`** — when every test in a file fails for the same root
   cause; one declaration is cleaner than 10 decorators.

   ```python
   pytestmark = pytest.mark.skip(
       reason="Deferred to 1.1.1 — Category X. See docs/..."
   )
   ```

All skip-reason strings include the category letter and a pointer back to this file
so `pytest --collect-only -q` or run logs make the rationale obvious.

## 1.1.1 Reactivation Checklist

When the upgrade begins, walk this list top-down:

1. **Fix Category A** (the harness mid-stream read). This single fix unlocks A, B, C, G
   simultaneously — about 80% of the deferred surface.
   - Rewrite `send_query_and_get_response` and `send_query_on_page` to wait for the
     Worker message (contract-002 with structured `cypher` / `data` blocks), not the
     first assistant message after submit.
   - Add a small fixture-level helper `wait_for_worker_response(page, prev_count)`
     that counts assistant messages before sending and waits for `count >= prev + 2`
     (preamble + worker) before reading.
2. **Resolve Category F**:
   - Reconcile `deploy/k8s/secrets.yaml` REDIS_PASSWORD with the test hardcode (or
     parameterize the test via env var).
   - Re-check `/api/health` cascade path under cluster — confirm honeybadge-server
     can reach Nebula/Redis/Audit MCP from the namespace.
3. **Resolve Category E** sub-issues individually (`el-dropdown` hover, reload race).
   - TC-005: switch to `click` trigger or programmatic dropdown open instead of
     hover-on-nested-span.
   - TC-205: wait for `page.evaluate(() => window.matrixClient?.isInitialSyncComplete?.())`
     before asserting.
4. **Resolve Category H** (NebulaGraph data rows) — verify seed/migration parity
   between local docker compose and the k3s cluster.
5. Per file, remove the `pytestmark = pytest.mark.skip(...)` line or the per-test
   `@pytest.mark.skip(...)` decorators. Run that file in isolation.
6. After each file passes locally, run the full e2e suite once to confirm no
   cross-file regressions before moving to the next.
7. Delete this tracker doc as the final step of the 1.1.1 milestone.

## Out of Scope for 1.1.1 Reactivation

- Do **not** re-add CRLF, do **not** revert PR #110 (TC-308 Matrix provisioning fix),
  do **not** undo the `aigw-local.hiclaw.io:8080` Docker alias workaround. These are
  load-bearing 1.1.0 hardening that 1.1.1 should build on, not replace.
- The skipped tests are valid assertions about real product behavior. Resist the
  temptation to "fix" them by weakening the assertion (e.g., asserting on the
  preamble text instead of the worker response). If a test no longer reflects
  intended behavior, delete it and write a new one — don't lower the bar.
